功能

该有的都有，不该有的都没有

打开就是课表：没有开屏广告、没有注册、没有多余权限。数据只存在你自己的设备上。

周视图 / 今日 / 下一节课

横竖都能滚，单双周与分段周次按真实范围显示；「今日」只列今天的课，下一节课带倒计时。

手表端同步

Wear OS 表盘复杂功能直接显示「下一节课」，还有信息块（Tile）；手机同步后自动推送到手表。

大屏与折叠屏

平板用侧边导航 + 双栏详情；折叠屏按铰链位置分栏，展开后课表与详情各占一半。

导入 / 导出课表

导出成 JSON 文件备份或换机迁移，导入后立即生效；走系统文件选择器，不需要存储权限。

作息时间对齐学校

按学校作息表显示上课时间；F、G 座教学楼的 3、4 节自动提前 10 分钟提醒。

离线可用

课表缓存在本机，没网也能看；换周、切天、看详情都不会转圈等网络。

界面

M3 组件，为「看一眼就走」排版

大标题写周次、色块区分课程、灰底标出没课的时间段；课程详情从底部 sheet 展开，不打断当前页面。

色块 = 课程识别
每门课自动分配稳定颜色，周视图 / 今日 / 详情保持一致，深浅色下重新调对比度。
课程详情 sheet
点色块看课程名、教师、教室、周次、节次，以及距离上课还有多久。
深浅色主题
跟随系统或手动切换，使用 M3 Expressive 的配色与 emphasized easing 动效。
数据源

两种方式拿到课表，默认用更准的那个

课表只在你自己的设备上解析和保存，不经过任何第三方服务器。

默认

分享链接 / token

把课表分享链接（或其中的 token）粘贴进设置即可，无需登录；数据与教务系统分享页一致，周次最准。

备选

教务系统登录

应用内打开教务系统登录页（账号 + 验证码或扫码），保存会话后自动同步；适合拿不到分享链接时。

迁移

课表文件导入导出

导出当前课表为 JSON 文件，换设备时导入即可恢复，不依赖原数据源是否可用。

常见问题

你可能想知道

会收集我的账号或课表吗？

不会。课表解析、缓存、登录会话都只保存在手机私有目录；应用没有服务器，也不含统计 SDK。设置里可随时清除缓存与会话。

为什么默认用分享链接，而不是自动登录？

分享页数据与学校实际课表一致；直接抓取教务系统时周次有时会和实际不一致，所以放在备选位置。

手表上可以登录教务系统吗？

不行。新数据源下由手机同步成功后推送到手表，手表设置页会提示「课表由手机同步」。

支持哪些系统版本？

手机端 Android 6.0（API 23）及以上，手表端 Wear OS 3（API 26）及以上；界面基于 Material 3 Expressive。

课表解析失败怎么办？

先确认链接 / token 未过期；仍失败请在 GitHub 提 issue，附学校名称与失败提示文本（不要贴账号密码）。
